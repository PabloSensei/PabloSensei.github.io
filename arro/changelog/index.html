#

Arro 0.1.19

17 November 2026 Latest · Release page

Faster completion and navigation, themes you can pick and write yourself, a Git branches popup like IntelliJ IDEA's, highlighting for sixteen more languages, database drivers that download themselves, a lot of editor polish, and the first piece of the AI agent panel back in the build.

New 8

  • Themes. Seven built-in themes: Dark, Light, High Contrast, Retro, Nord, Mocha and Paper. Settings → Appearance shows them as cards for the light and dark system appearance, and Sync with OS follows the system's light or dark mode as it changes. Quick Switch Scheme (Ctrl+\) previews a theme as you move over it; Esc goes back. A theme is a short JSON file that can inherit from another one: drop it in the themes folder of your settings, or **Import…** an IntelliJ IDEA .icls` color scheme.
  • Git branches popup like IntelliJ IDEA's. Click the branch name in the title bar: a search field for branches and actions on top, then Update Project, Commit, Push, New Branch, Checkout Tag or Revision and Stash, then Recent, Local, Remote and Tags. Branch names fold into folders by their slashes (feature/auth/login), remote branches group by remote. Star your favourite branches; main, master and develop start as favourites. The arrow on a branch opens Checkout, New Branch from, Compare, Show Diff, Rebase, Merge, Push, Rename and Delete; the keyboard works throughout.
  • Change marker popup. Hover or click the green or blue bar next to the line numbers to see the original text with the changed words marked, and to roll the change back, copy it, open the diff or jump to the next change. The scrollbar marks every change in the file. Marks now follow your edits right away, not after a save.
  • Syntax highlighting for sixteen more languages: Python, C, C++, C#, Go, Rust, Scala, PHP, Ruby, Swift, Lua, PowerShell, Protobuf, INI, diff and Makefile, with folding and indentation. Code blocks in Markdown are highlighted too.
  • Database drivers download themselves. A data source without a driver shows Download driver: the newest stable version comes from Maven Central, the official channel of the PostgreSQL, MySQL, MariaDB, SQLite, H2, SQL Server and Oracle drivers, its checksum is verified, and the jar is kept in Arro's data folder. You can pick another version. When a connection fails, Arro now says why: no driver, a refused password, a server that does not answer.
  • Database passwords in the system keychain. Save password in a data source keeps the password in Windows Credential Manager, the macOS Keychain or the Linux Secret Service (secret-tool from libsecret-tools), never in a project file.
  • File type icons for Python, C, C++, C#, Go, Rust, Scala, PHP, Ruby, Swift, Lua, PowerShell, Protobuf, Kotlin, Groovy, JavaScript, TypeScript, JSON, YAML, TOML, SQL, HTML, CSS, Markdown, shell scripts and Dockerfiles, in the project tree, tabs, Search Everywhere and Recent Files.
  • AI Sessions panel, early preview. The agent panel is back in the build: a chat with Claude Code or Codex through the Agent Client Protocol (Node.js is needed for npx), @ mentions of project files, and a review of the agent's changes hunk by hunk. It is not finished, and we have not yet tried it with every agent; this is the first of several small steps.

Improved 20

  • Completion and navigation are much faster. Usage counts above declarations no longer search the whole project again on every key, which held completion back for seconds. On Spring PetClinic (our measurement): completion after a dot in about 0.3–0.6 s, the next letter in an open list in about 0.1 s, Ctrl+B in 0.1–0.3 s, a repeated Ctrl+B into the JDK in under 0.2 s. Ctrl+B and Ctrl+N use Arro's own index while the Java server is still importing, and the status bar shows that it is not ready yet.
  • Completion like IntelliJ IDEA. An exact match of what you typed comes first, then locals and fields, then common java.lang types, so Str gives String first. The list filters in place as you type, scrolls, takes the mouse (click to select, double-click to insert) and PgUp/PgDn/Home/End. Documentation of the selected item loads in the background. Stale requests are cancelled as you type.
  • Ctrl+B jumps at once when there is one target and lists them when there are several; inside the current file it stays in the same tab, and Back returns. "Cannot find declaration" fades by itself.
  • One editor popup at a time. Alt+Enter, completion, Parameter Info, documentation and notes no longer cover each other; Esc closes the topmost one, and switching tabs closes them.
  • Breakpoints on the line number. Click a line number to set or remove a breakpoint, drag over the numbers to select lines. Breakpoint icons no longer sit on the digits.
  • The line number column grows with the length of the file, so line 5238 is shown in full.
  • Interface scale now scales the whole window on Windows — icons, panels, spacing and text. On macOS and Linux it scales text for now.
  • Window title bar. Double-click the empty title bar to maximize and restore. On Linux with client-side decorations the window edges and corners resize the window. On Windows the minimize, maximize and close buttons keep working after the window is resized or snapped.
  • Alt+Enter like IntelliJ IDEA. Quick fixes come first with a red bulb, intentions after them with a yellow one, and the change of the selected action is previewed on the right when the language server sends it. The same action is no longer listed twice. With nothing to offer, "No actions available here" fades by itself.
  • Selection. Dragging after a double-click selects whole words, after a triple-click whole lines.
  • Ctrl+B on a declaration lists its usages, or jumps to the only one, as in IntelliJ IDEA.
  • Completion list: kind icons next to every entry (class, interface, enum, method, field, variable, keyword, template), and the documentation of the selected entry is rendered instead of shown as raw Markdown.
  • Auto-import puts the new import inside a folded import block, where it belongs.
  • The Git change popup no longer takes the focus: keep typing, Esc or a click elsewhere closes it.
  • Search Everywhere, Go to Class and Go to File redraw at once as you type.
  • A shortcut such as Ctrl+\` no longer types its character into the editor.
  • Pasting several lines into the terminal asks with Paste and Cancel buttons, next to the terminal.
  • The Run/Debug Configurations dialog is larger, and its fields scroll above the buttons.
  • The branches popup shows an icon for Commit and one star per favourite branch.
  • The editor redraws at once after the interface scale changes.

Fixed 2

  • Dragging the last tab of a split editor group to another group no longer crashes Arro.
  • The third-party notices now name the libraries inside the bundled java-debug jar.

Arro 0.1.18

16 November 2026 · Release page

Spell checking, Kubernetes in the Services window, a table data editor, Jakarta EE, Quarkus and Micronaut, sequence diagrams, heap dump analysis, Flyway and Liquibase migrations, and an .rpm package for Fedora and openSUSE.

New 8

  • Spell checking. Typos in comments, Javadoc, string literals, declaration names, Markdown, .properties, YAML and XML comments get a green wavy underline. camelCase and snake_case words are split, and short words, URLs, paths and hex are skipped. Alt+Enter offers up to five replacements: a typo in a declaration is fixed through Rename, so its usages change too. You can also save the word to the project or application dictionary, or turn the check off. Words come from the system spell checker on Windows and macOS and from hunspell or /usr/share/dict/words on Linux. Settings → Editor → Spelling edits your dictionary, and the Typo inspection has its own level.
  • Kubernetes. The Services window has a Kubernetes node next to Docker: contexts and namespaces from your kubeconfig, then pods, deployments, stateful sets, services, config maps, secrets, ingresses, jobs and cron jobs with their state. Pod logs (also of the previous container), Describe, View YAML with edit and Apply, Delete, Restart, Scale, Port Forward and Exec in the terminal. Secret values stay hidden until you ask for one. A YAML manifest in the editor gets a gutter mark per document with Apply to Cluster, Diff with Cluster and Delete from Cluster. The cluster is polled only while the node is open, and Arro waits longer between tries when the cluster is unreachable. Settings → Tools → Kubernetes sets the paths to kubectl and kubeconfig.
  • Jakarta EE, Quarkus and Micronaut. The Beans window and the gutter injection marks now understand CDI scopes, @Named, custom qualifiers and @Produces, and Micronaut @Singleton, @Prototype and @Factory beans. Missing and ambiguous beans are reported at @Inject. application.properties and .yml get completion, hover and checks from Quarkus and Micronaut metadata, @ConfigMapping and @ConfigProperties classes, and Quarkus %dev/%test/%prod profiles. Keys in @ConfigProperty and @Property complete and navigate. The Endpoints window lists Micronaut controllers and Quarkus reactive routes on the right port. Quarkus modules get a Dev Mode run configuration.
  • Sequence diagram. Generate Sequence Diagram in the editor menu or Find Action draws the calls of a method. Project calls are followed to the depth you choose; library calls end at one external participant. Return values, activations, and alt/opt/loop frames come from if, switch and loops. Getters, setters, private methods and constructors can be filtered out. The diagram appears while it is still being built. Double-click a message to jump to the call; hide participants. Export to SVG, PlantUML or Mermaid.
  • Heap dumps. Capture Memory Snapshot in the Run, Debug and Profiler windows takes a heap dump of the running app with jcmd, and File → Open opens any .hprof. You get a class histogram with shallow and retained size, the dominator tree, the biggest objects and duplicate strings. Each instance shows its field values, references you can follow, and its shortest path to a GC root. The file is read in the background with progress and Cancel. Settings → Debugger sets the snapshot folder.
  • Flyway and Liquibase. The project tree and the Database window show a Migrations node: Flyway V/U/R scripts in version order, and Liquibase changelogs in XML, YAML, JSON or formatted SQL with their includes. With a database connected, each migration is marked applied, pending, failed or changed since it was applied. Duplicate versions, bad file names, edited applied migrations, missing includes and duplicate change sets are reported as inspections. Liquibase changelogs get completion of change sets and changes. Migrate, Info, Validate and Clean run through the Maven or Gradle plugin, and Clean asks first.
  • Table data editor. Double-click a table in the Database window, or choose Open Data, to open its rows in a tab: pages of 500 rows, a WHERE filter, and sorting by a click on a column header. Edit cells, set NULL, add and delete rows. Submit (Ctrl+Enter) writes all edits in one transaction and rolls it back if a statement fails; Revert drops them. Closing a tab with unsaved edits asks first. Views, and tables without a key, are read-only. Copy cells as TSV, CSV or INSERT statements.
  • .rpm package and a home install on Linux. Fedora and openSUSE: sudo dnf install ./arro-0.1.18-1.x86_64.rpm puts Arro in /opt/arro with arro on the path and a menu shortcut. Without root, ./install.sh from the tar.gz installs into ~/.local/share/arro with a link in ~/.local/bin and a menu entry, and ./install.sh --uninstall removes it.

Improved 3

  • On Windows and macOS the system spell checker runs on one dedicated thread. On macOS each request gets its own autorelease pool, and Arro falls back to hunspell when no English dictionary is installed.
  • The class diagram and the sequence diagram share the same pan, zoom and fit.
  • Development builds take much less disk space.

Arro 0.1.17

15 November 2026 · Release page

Packages for Linux (.deb) and macOS (.dmg), a New Project wizard with Spring Initializr, terminal tabs and splits, run configurations with Before launch and Compound, class diagrams, a Resource Bundle editor, Structural Search and Replace, Create Test, a Services window, inspection settings, the code style of IntelliJ IDEA projects, and a deeper debugger.

New 17

  • Resource Bundle editor. A messages*.properties file gets a Bundle tab: every key of all locales in one table with a filter, a field per locale, missing translations marked, add, remove and rename a key in all files at once. Edits go through the normal buffers, so Undo and Save work as in the text.
  • Class diagram. Show Diagram (Ctrl+Alt+Shift+U, or the menu of a class or a package folder) draws the class with its ancestors and project subclasses, or a whole package: fields, methods, inheritance, implementation and associations. Pan, zoom, drag nodes, add a class, hide members, double-click to go to the source, export to SVG.
  • Structural Search and Replace. Search by a code template with $variables$, count, text and type filters, 15 ready templates, and a replace preview; results open in the Find window.
  • Create Test. Go to Test on a class without tests offers Create New Test, also on Alt+Enter: JUnit 5, JUnit 4 or TestNG, class name, package, setUp/tearDown and the methods to test, with a Fix button when the library is missing from the build.
  • Services window. Run configurations next to Docker: Spring Boot apps and other main classes with their state and port, start, stop and restart, the console and Actuator of the same run, open in the browser or in the HTTP client.
  • Run configurations in depth. Before launch steps (build, a Maven goal or Gradle task, another configuration), Compound configurations that start and stop several together, Allow multiple instances with a Stop and Rerun question otherwise, an environment file (.env) per configuration, and Stop that cancels a launch still being prepared. The test window can rerun the last tests after each save (Auto) and keeps the last 10 runs in History.
  • Inspection settings. Settings → Editor → Inspections lists the checks of Arro and the Java compiler: turn each one on or off and choose its level, saved in the project. Alt+Enter on a warning can suppress it for the statement, method or class, disable the check or open its setting.
  • Coming from IntelliJ IDEA. A project with .idea/codeStyles/Project.xml keeps its style: indents, tabs and the right margin in the editor, and the Java formatter and import order through the language server. .editorconfig still wins, and Settings → Editor → Code Style shows which file is used, with a Use Arro settings button. File → Manage IDE Settings exports and imports the settings, keymap and templates of Arro as one zip, without passwords and tokens.
  • Dependency updates. pom.xml, build.gradle(.kts) and libs.versions.toml mark versions with a newer stable release; Alt+Enter updates to the latest or the latest patch, and version completion lists what the repository has.
  • HTTP client and cURL. Pasting a curl command into an .http file turns it into a request; Copy as cURL goes the other way (bash or cmd). Response handler scripts, multipart bodies and comparing two responses.
  • Git history of a selection or a method. Show History for Selection and for Method, with the diff of each commit; Git submodules are recognized and updated together with the project.
  • New Project wizard. Java projects with Maven or Gradle (Groovy or Kotlin DSL), a JDK from the ones found, sample code and GroupId/ArtifactId/Version; Spring Boot projects from Spring Initializr with a searchable dependency list; empty projects; an optional Git repository. Also from File → New → Project... in an open window.
  • Terminal tabs and splits. Several sessions as tabs (Ctrl+Shift+T, rename, Alt+Left/Right) with a shell picker (PowerShell, cmd, Git Bash, WSL; $SHELL, bash, zsh, fish), Split Right and Split Down, Ctrl+F through the whole scrollback with case and regex, Ctrl+click on URLs, file paths with a line, compiler output and Java stack frames, mouse selection with copy and paste, and tabs restored after a restart. Open in Terminal on a project folder opens a tab there.
  • Appearance modes. View → Appearance: Full Screen, Distraction Free, Zen and Presentation modes, toggles for the toolbar, tool window bars, status bar, breadcrumbs, line numbers, gutter icons, indent guides and sticky lines, and Zoom IDE (Ctrl+Alt+Shift+= / - / 0).
  • Packages for Linux and macOS. A .deb for Debian and Ubuntu (sudo apt install ./arro_0.1.17_amd64.deb: Arro in /opt/arro, arro on the path, a menu shortcut) and a .dmg for macOS. A package installation gets a link to the new package when an update comes out; the zip and tar.gz archives keep updating themselves.
  • macOS and Linux integration. On macOS the Arro application menu (About, Settings, Hide, Services, Quit) and the Window menu work as in other Mac apps. Folders and Java, Kotlin, Gradle, Maven, Markdown, YAML, JSON and XML files open from Finder or the file manager with Open With, and arro <path> hands the path to the running Arro instead of starting a second copy (--new-instance starts one anyway). Linux keeps its cache in $XDG_CACHE_HOME and groups its windows under the Arro icon.
  • Debugger. Mark Object (F11) labels an object in all views, Copy Stack, library frames folded into one line, inline watches on a line, and type renderers.

Improved 2

  • Stack trace analysis shows project frames at once and fills library frames in after.
  • The Database and JShell windows no longer poll when nothing is connected.

Fixed 3

  • The editor context menu has its separator before Copy Path again.
  • File → Exit asks about unsaved edits made in the Resource Bundle table for files without a tab, names them, and saves or drops them as chosen.
  • Several window tests that failed only under heavy machine load are stable now.

Arro 0.1.16

14 November 2026 · Release page

The biggest batch so far: Spring support, a database console, a profiler, JShell, a dependency analyzer, stack trace analysis and a live Actuator tab for Spring Boot apps.

New 16

  • Spring configuration files. application.properties and application.yml get completion, hover documentation, Ctrl+B and checks for unknown or deprecated keys and wrong boolean or enum values, from the configuration metadata of the jars and the build output on the class path.
  • Beans window and injection navigation. Components, configuration classes, @Bean methods and Spring Data repositories of the project; gutter marks on injection points and beans go to the candidates.
  • Endpoints window. Every @RequestMapping, @GetMapping and friends with its HTTP method and full path; a gutter mark on each handler; one click writes the request into an .http file of the HTTP client.
  • Spring Data JPA. Repository method names like findByLastNameStartingWith complete properties and operators from the entity, mark an unknown property and a wrong number of parameters, and Ctrl+B goes to the field. JPQL in @Query (text blocks too) is highlighted, completes entities and properties after an alias, checks them and the :name parameters.
  • Actuator tab for Spring Boot. A running Spring Boot app gets an Actuator tab next to its console with live Health, Beans, Mappings and Environment, a green dot when the app has started, a jump from a bean or handler to its code, and a hint when an endpoint is not exposed.
  • Message bundles. Keys in getMessage, ResourceBundle.getString, validation message = "{…}" and Thymeleaf #{…} go to their line in messages*.properties with Ctrl+B, complete, show every locale on hover, and warn when missing, with a Create property fix. Property files mark unused keys and missing translations; Find Usages and Rename work on a key.
  • Database window. JDBC data sources (PostgreSQL, MySQL, MariaDB, H2, SQLite and any driver jar), found from spring.datasource too; a schema tree, an SQL console with Ctrl+Enter and results in a grid.
  • Profiler. Run with Profiler records a Java Flight Recorder file: CPU and allocations as a flame graph, a call tree and a method list, Allocated Types by weight, and a thread timeline where a dragged range filters the graphs. Tests (Run Tests with Profiler) and Maven/Gradle tasks such as test, spring-boot:run and bootRun can be profiled too; opening a .jfr file works as well.
  • JShell console. JShell Console (View → Tool Windows or Find Action) opens a .jsh scratch per module on its class path: Ctrl+Enter runs the selection or the whole file, results show as ==> 42, with Stop, Reset and completion from JShell.
  • Dependency Analyzer. The Maven and Gradle dependency tree with conflicts, the version that won, the path that brought each dependency, and an Exclude action.
  • Library sources. Download Sources for all libraries or one class, Choose Sources for a jar, and an option to fetch sources on import.
  • Analyze Stack Trace and thread dumps. Paste a stack trace or a jstack dump to get clickable frames, threads by state and a deadlock mark; Dump Threads in the Run window reads a running JVM with jcmd.
  • Debugger values inline. Variable values appear at the end of the lines during a debug session (can be turned off); Remote JVM Debug attaches to a running JVM.
  • Actions on Save. Reformat (whole file or changed lines) and optimize imports on save, per file mask.
  • Compare with Clipboard in the editor menu and Find Action.
  • Markdown preview pictures from the project and the web, and the preview mode of each file is remembered.

Improved 2

  • New tool window icons for Database, HTTP Client and Endpoints; the Switcher lists the new windows.
  • Search Everywhere and Go to Class on a small project answer in the same frame.

Fixed 3

  • Typing in a large merge result no longer eats memory: the editor counts the widest line once per frame and caches it.
  • The debugger adapter closes cleanly when its last session ends.
  • Linux and macOS: the whole test suite is green on both systems.

Arro 0.1.15

14 November 2026 · Release page

Coverage, an HTTP client and interactive rebase; the Debug and Services windows are rebuilt; Linux and macOS get fixes and are now tested before every release.

New 6

  • Run with Coverage. Runs and test runs (Maven, Gradle, a main class) can collect coverage with JaCoCo. The gutter marks covered, partly covered and missed lines, with the hit count on hover; the Coverage window lists packages and classes with Class, Method, Line and Branch percentages; the project tree shows the line percentage. Ctrl+Alt+F6 shows or hides it.
  • HTTP client. .http and .rest files run requests: a Run icon on every request, Ctrl+Enter at the caret, {{variables}} from http-client.env.json with an environment list above the file, $uuid, $timestamp and $randomInt. The HTTP Response window shows the status, headers and the body, JSON indented and coloured, and keeps the last 50 responses. New → HTTP Request makes one.
  • Interactive rebase. Interactively Rebase from Here in the Git Log commit menu: Pick, Edit, Reword, Squash, Fixup and Drop (keys P, E, R, S, F, D), Alt+Up and Alt+Down reorder, Reword edits the message in place; Edit and conflicts stop with Continue Rebase and Abort.
  • Markdown highlighting inside lines: bold, italic, strikethrough, inline code, links, and code blocks coloured in their own language.
  • Breakpoints that do not stop. In the properties of a breakpoint, turn Suspend off and log a "Breakpoint hit" message, the value of an expression, or both; Shift+click in the gutter sets such a point.
  • README on first open. A project opened for the first time shows its README as a preview (Settings → Project can turn it off).

Improved 2

  • Debug window rebuilt like IDEA: an icon toolbar (Rerun, Resume, Pause, Stop, Step Over, Step Into, Step Out, Run to Cursor, Drop Frame, Evaluate, View Breakpoints), Debugger and Console tabs, frames beside Variables and Watch with a movable divider.
  • Services window rebuilt like IDEA: containers grouped by compose project with a running counter, icon buttons, logs that start when you select a container or project, Dashboard and Console tabs, a right-click menu (Start, Stop, Restart, Remove, Show Logs, Exec, Copy Container ID; Up, Down, Restart, Stop for a project) and a movable divider.

Fixed 4

  • On Linux and macOS, saving a read-only file replaced it silently; it now fails as on Windows.
  • Field watchpoints now stop on the real Java debugger; they used to stay unverified.
  • One file no longer opens in two tabs when its path is typed in another case (Windows, macOS).
  • The macOS app now carries the Maven extension and the test listener it was missing, and finds them, the language servers and the notices inside the bundle.

Arro 0.1.14

14 November 2026 · Release page

Git grows up, the debugger learns new breakpoints, and Markdown gets a preview.

New 9

  • Three-way merge. Merge… in the Conflicts window (or a double click) opens Yours, Result and Theirs side by side. Non-conflicting changes are already applied; take or drop each chunk with the arrows and the cross, walk the conflicts with F7 and Shift+F7. Apply asks first if conflicts are left, writes the file in its own encoding and line endings only if it did not change on disk meanwhile, and only then marks it resolved. Cancel leaves the file and the index alone.
  • Git Annotate. Annotate with Git Blame in the gutter menu shows the date and author of every line; hover for the full commit, click to open it in Git Log.
  • Branch graph in Git Log, with branch and tag labels and HEAD marked.
  • Commit actions in Git Log: Copy Revision Number, Checkout Revision, New Branch, New Tag, Cherry-Pick, Revert Commit, Reset Current Branch to Here (Soft, Mixed, Hard, Keep) and Compare with Local.
  • Debugger: method breakpoints (click the gutter on a method declaration), field watchpoints (on a field declaration or from Variables) and Drop Frame.
  • Refactor This (Ctrl+Alt+Shift+T) lists every refactoring that applies at the caret, with its keys. New from the language server: Extract Interface and Extract Field with their dialogs, Make Static, Surround with try/catch, Convert to lambda and more.
  • Markdown preview beside the editor, with Editor only, Editor and Preview and Preview only; it follows the editor scroll and opens links, project files and anchors.
  • More highlighting: Gradle scripts (Groovy and Kotlin), Kotlin, Groovy, TOML, SQL, HTML, CSS, JavaScript, TypeScript and Markdown.
  • Settings opens with the caret in its search field; the arrow keys walk the pages.

Fixed 1

  • Programs started from Run configurations and builds could leave console programs running after they stopped, when those programs escaped the process job; they now end with their owner, while window programs you started stay open.

Arro 0.1.9

13 November 2026 · Release page

Smaller fixes and groundwork for Linux and macOS.

Linux archive: needs glibc 2.43. The Linux build of 0.1.9 was made on a runner with glibc 2.43, so it does not start on Ubuntu 24.04, Debian 12 or other systems with an older glibc (version 'GLIBC_2.43' not found). The next release is built against glibc 2.35 and runs on Ubuntu 22.04 and newer.

Fixed 4
