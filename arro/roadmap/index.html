Arro Changelog Help Roadmap

Roadmap

What is coming, in the order it is being built. No dates: a step is done when it is good, and it shows up in the changelog.

In progress · next release Next Later

In progress

For the next release, after 0.1.25

  • Git blame on every line

    Annotate shows the author and date of each line, and the gutter of line numbers gets its own right-click menu.

  • Changed files with their icons

    File type and folder icons in the changed files of the Git log, the commit and the shelf.

  • More IDE tools for agents over MCP

    File, search, run configuration, debugger and database tools, and one-click setup of the MCP server for Claude Code, Codex, Cursor and other clients.

  • A Build window

    Build output as a tree of errors and warnings by file, with a double click to the line, and Rebuild Project and Build Module in the Build menu.

  • Refactoring dialogs

    Extract Variable, Constant, Parameter and Method ask for the name and can replace every occurrence; a refactoring over many files is undone in one step.

  • Pull Members Up and Push Down

    Pull Members Up, Push Members Down, Extract Superclass and Introduce Parameter Object.

  • A shorter Generate menu

    Alt+Insert offers only what fits the class: no getters without fields.

Next

After that

  • Maven and Gradle profiles

    Pick the active profiles of a project and pass them to its tasks.

  • Modules in Project Structure

    A page for the modules of a project, and a language level you can change.

  • Type Hierarchy and Bookmarks windows

    Type hierarchy as a tree you can expand and walk, and bookmarks in their own window with groups and search.

  • Move members

    F6 on a method or a field moves it to another class.

  • Spring configuration navigation

    Ctrl+B from a property lands on the field of its configuration class, and from @Value("${...}") on the key.

  • Flatpak and Homebrew

    Packages for Flatpak on Linux and Homebrew on macOS.

  • A notarized macOS build

    So the first start on a Mac needs no extra step.

  • A responsiveness pass

    Measured latency budgets, and the work to meet them.

Later

Further out

  • Arro’s own Java index

    Its own index, completion and diagnostics for Java, without waiting for the language server.

  • Deeper Docker and agent tooling

    More of the container and agent workflow inside the IDE.

  • Kotlin

    Kotlin projects on the same core.

Something missing that you need? Open an issue and say what you would use it for.
