Arro

Rust · Windows, Linux and macOS · free

A native Java IDE written in Rust. IntelliJ-style workflow and shortcuts, a GPU-rendered UI, and a fraction of the memory.

  • Native and fast. Rust from top to bottom and a GPU-rendered UI on GPUI. No Electron, no web view.
  • Feels like home for IntelliJ users. The same shortcuts, menus and tool windows.
  • Never freezes on a tool. Builds, Git, the language server and the debugger run outside the UI thread.
  • Moving fast. 20 releases so far; the latest, 0.1.19, came out on 17 Nov 2026.

dictate

Rust · whisper.cpp · CUDA · MIT licence

Private, offline push-to-talk dictation. Hold a key, speak, let go: the text is typed into whatever app you are in.

  • No network code at all. Block it in the firewall and it keeps working.
  • About 0.16 s to recognise a five-second phrase on an RTX 4070 Ti with Whisper large-v3-turbo, measured by the author.
  • One exe, about 4,500 lines of Rust you can read in an evening. Voice activity detection, vocabulary hints, autocorrect rules.

Tunetop

Python · Windows 10 and 11

A small always-on-top music widget that controls any player through the Windows system media controls.

  • Any player, no plugins. Spotify, browsers, foobar2000, AIMP, MusicBee, VLC and anything else on the system player.
  • Three views: full, a slim bar and cover only. Skins are a folder with a skin.json; colours can follow the album art.
  • Synced lyrics, per-player volume, global hotkeys, 13 interface languages.

AI Translator

Electron · Windows, macOS and Linux

A desktop translator on Gemini, Claude and OpenRouter: hotkeys, screenshots, styles and history.

  • Select, press, read. Select text in any app and press Ctrl+Shift+Y, or paste a screenshot and the model reads the text in it.
  • Translate or Fix text modes, ten styles plus your own, results streamed word by word.
  • The last 100 translations with search, favourites and export to CSV, JSON or Markdown.
