Why Bowyer

  • Every agent, one place

    Claude Code, Codex, OpenCode and DeepSeek each keep their history in their own folder, their own format and their own terminal. Bowyer reads all of them and shows every session you ever ran, on this machine and on your servers, in one tree you can search as you type.

  • Native and fast

    Rust from top to bottom and a GPU-rendered UI on GPUI, the same foundation as Arro. No Electron, no web view. Hundreds of sessions load in a moment.

  • Watch them all at once

    Mission control lays every running agent out in a grid of live cards: what each one is doing, how full its context is and what its turn costs. Answer a permission question on the card, or click it to jump into the session.

  • Your files stay yours

    Bowyer only reads what the agents write. Folders, pins, names and notes live in its own database, and your agents keep working exactly as before, with or without the window open.

  • See what it costs

    The context window split by what fills it, token totals, cost at API prices, and a countdown for the prompt cache, so you know when compacting pays off and when a pause will make the next turn expensive. For a Claude subscription, the five-hour and weekly limits; for an API key, this month's spending.

  • Keep going from the window

    Type a message and the agent runs the turn in the background, here or on an SSH host. Every session has its own turn, composer, model and effort, so several run at once. The answer streams in, and permission prompts and questions arrive as buttons instead of a terminal you first have to find.

What it does

Reads the sessions of Claude Code and OpenCode every day, Codex and DeepSeek Harness too, on this computer and on any host you reach over SSH.

Every session in one tree

Grouped by environment, agent and project, or by any one of them, with your own folders, drag and drop, pins, renames and four sort orders. Sub-agent and worktree sessions fold under the session that started them, and so do sessions Claude's desktop app started separately; long projects show the latest ten and a Show more; one button collapses everything. A session you no longer need goes to a trash folder, and both side panels hide into thin stripes at the edges.

Sessions running in a terminal elsewhere show working, waiting or your turn, and the taskbar flashes when one needs you. Ctrl+K searches titles, prompts, folders and the whole conversation text, and shows the sentence where your words matched. Each agent has a pixel critter of its own, so you tell them apart at a glance.

A chat, not a terminal dump

Markdown, highlighted code with Copy and Run, folded thinking, and tool calls folded into one line per run that opens into the commands, their output and the diffs. Background task notices shrink to a short line, and so do what a hook told the model and the long summary an agent writes when it compacts the context.

Paste screenshots, drop files, / for commands and skills, @ for files of the session's folder. Claude Code and OpenCode ask before a command or an edit their settings don't allow, right in the window, and Claude's questions come with their choices and a field for your own answer.

Send another prompt while a turn runs and it goes next. The view stays where you read while new text arrives. A prompt that never reached the model can be deleted, and the session goes on from the answer before it.

What a session holds

Environment, folder, Git branch and model. The context window split by what fills it, for Claude Code exactly as Claude counts it: system prompt, tools, MCP servers, skills and messages.

The plan's five-hour and weekly limits, or an API account's spending this month. Token totals, cost at API prices per call, the price of the next turn and of a compaction at the current cache state, and how long the prompt cache stays warm. Every file the session changed, as a tree, and every command and sub-agent it ran, the latest first. Each section folds by its title.

Files, Git and a terminal

A Files tab with the folder's tree and a preview of text and pictures, here or over SSH. A Changes tab with staged and unstaged files, diffs by hunk with Stage, Unstage and Discard, commit, fetch, pull, push and branch switching.

Built-in terminals (Ctrl+`) open as tabs under the conversation, in the session's folder, locally or on the SSH host, so resuming a session never starts with hunting for the right window. Each session keeps its own terminals, and on Windows a list opens PowerShell, Command Prompt, Git Bash or WSL. Claude Code sessions connect to the IDE that has their folder open.

SSH hosts

Add user@host with a key of its own or a password kept by the system (Credential Manager, the macOS Keychain or the Linux keyring); the connection is checked before it is saved, and an unknown host shows its key fingerprint first. Sessions, files, Git, the terminal and new turns work on the host as they do here.

Memory for your agents

bowyer mcp is an MCP server with one recall tool: an agent asks whether a problem was solved before and gets the past sessions of the project with their fix, commit and ticket, then reads what it needs. Switch it off everywhere or for one project.

And the rest

MCP servers and plugins of each agent at a glance, eight themes (the newest is the violet Nightfall) and your own, eight languages, all settings in one dialog, a notification area icon on Windows and Linux, a question before quitting with sessions still running, and updates from a signed feed that install only when you click.

The Windows installer sets Bowyer up for the current user, without administrator rights; it is not code-signed yet, so SmartScreen may ask you to choose More info, then Run anyway. Linux needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36, openSUSE Tumbleweed, Arch Linux or later); each Linux package is installed in a clean container of its distribution before a release. The macOS app is not notarized: Control-click it, choose Open and confirm the first time.
